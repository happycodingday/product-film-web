# LUMA 光遇 · AI 眼镜概念发布

[English](README.md) | **简体中文**

一支完整的 **61 秒虚构 AI 眼镜概念片**。沿用 PaperSkill 的播放器与发布会 UI，产品故事和动画独立设计。演出文案为中文，产品图和街景由 AI 生成。

## 启动

安装 Node.js 后，在本目录执行：

```sh
node serve.cjs 4186
```

打开 `http://localhost:4186/`；端口占用时换一个端口。无需 npm 安装。`?autoplay=1` 自动播放，`?clean=1&autoplay=1` 进入纯净播放。

## 分镜

| 时间 | 场景 | 动作 |
| --- | --- | --- |
| 0–8s | 抬头，世界就懂了 | 产品显现，缓慢转向与推近 |
| 8–16s | 是眼镜，也是新直觉 | 感知、聆听、提示依次点亮 |
| 16–26s | 看见它，就了解它 | 第一视角扫描街角，理解卡片浮现 |
| 26–36s | 你说你的，世界听懂了 | 双语对话与起伏声波 |
| 36–45s | 方向，就在眼前 | AR 路线流动，转向提示出现 |
| 45–54s | 精彩留住，生活继续 | 记忆卡片进入，输入提问找回片刻 |
| 54–61s | 把屏幕放下，让世界展开 | 居中产品与品牌收束 |

Space 播放/暂停，R 重播，H 隐藏控件，F 全屏，方向键切章节，进度条可定位。暂停后可以切换第二幕的感知选项、第四幕的对话和第五幕的目的地。点击章节显示该幕重点画面。

所有动画由主时钟统一驱动，支持回退与倍速。纯净模式不会开始录制，需另行使用录屏工具。本示例未配 BGM，也未导出视频。

## 素材与概念说明

产品、品牌、功能和 AR 画面均为虚构，不代表真实量产产品或硬件测试；画面中持续标有概念演示。未提供销量、价格或虚构官网。
